# BEHRAD IMAGE AI

AI image generation website powered by Pollinations AI.

## Features

- AI image generation
- Multiple image models
- Multiple image sizes
- Prompt enhancement
- Safe mode
- Seed control
- Image regeneration
- Local browser history
- Image download
- Prompt copy
- Responsive mobile/desktop UI
- FastAPI backend
- Render deployment ready
